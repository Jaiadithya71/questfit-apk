# QuestFit v0.4.0 APK

Progression and traveler-art update of the offline Android build. The private source repository is separate.

Download the APK from the v0.4.0 release assets on this page.

Before installing, back up any existing QuestFit progress. Updating over an older install has not been tested; do not uninstall the old app to force an update.

SHA-256: `00c824752f98662ed2408701d99bd63275a172a02e19da29d90e21dda3ad2f98`

What's new in v0.4.0: six original level-stage traveler artworks (slim beginner at Level 1 to radiant hero at Level 21+), an evolution reveal when a new stage is reached, and a Path of growth on the Journey screen. Still no cloud sync, AI plans, or exercise videos.
